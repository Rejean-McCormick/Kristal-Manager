# Sélection des sources métier

Le plan d'affaires est une source de **contexte de conception**, pas une autorité technique supérieure aux repos propriétaires.

Inclus :
- besoins et ruptures observées;
- actifs/composants et leurs rôles;
- capacités et principes de remplaçabilité;
- utilités, profils d'usage et workflow de qualification;
- éléments qui clarifient où une application périphérique s'aligne.

Exclus du canon architectural :
- prix et marges;
- projections de revenu;
- besoins de capital;
- hypothèses de marché non démontrées;
- choix de monétisation;
- claims commerciaux qui ne décrivent pas une capacité technique ou sociotechnique.

## Precedence added in v0.5

Current owner repository READMEs/contracts are preferred for self-declared implementation boundaries and versions. `kOA_Digital_Ecosystem` remains the cross-system ownership/integration map. Earlier public enumeration is retained as historical discovery evidence. Local presence alone never proves activation, deployment or kOA membership.
