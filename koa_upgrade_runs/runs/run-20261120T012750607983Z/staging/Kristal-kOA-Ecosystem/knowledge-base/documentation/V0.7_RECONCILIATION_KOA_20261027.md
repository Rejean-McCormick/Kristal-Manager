## Frontières de preuve

L'existence d'une ligne kOA **ne prouve pas** qu'un Git `origin` répond, qu'un dépôt existe encore sur GitHub, qu'un contrat est qualifié, ou qu'un push est autorisé. Les 7 identités de dépôts avec plusieurs dossiers sont distinctes, sans fusion silencieuse. Les projets `LOCAL/` ne sont pas des noms de dépôts GitHub.

Les données v6/v9 héritées restent canoniques pour ce package. Le Kit récent propose v11 en option, mais ce patch **n'effectue pas de migration des identités**. Le diK alpha.7 cible v11 draft.3, le Kit joint draft.4, et le Kristalizer embarque encore le pin du Kit draft.3 : les profils doivent être qualifiés explicitement avant co-utilisation. KristalDiag est indépendant, mais sa couverture annoncée est v10 draft.3.1 et ne prouve pas la conformité v11.

- **BoKristal et Spek** : distributions/projections autonomes, ne certifiant pas les engagements sémantiques Kristal.

- **Kor** : projection mobile, ne possède pas les états Konnaxion et Orgo.
- **KonnaxionDiag** : les deux anciens diagnostics Konnaxion sont représentés comme des sous-fonctions, non comme des nouveaux dépôts à pousser.
