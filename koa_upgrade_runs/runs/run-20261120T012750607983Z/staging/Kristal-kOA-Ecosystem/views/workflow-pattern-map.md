# Workflow pattern map

Chaque pattern est une composition potentielle; les capacités liées décrivent ce qu’il faut mobiliser, pas une preuve de déploiement.

## Investigate a signal
Move from a symptom, signal, or anomaly to structured understanding.

**Utilité(s):** Find & Understand

**Capacités habilitantes :**
- Extraction de candidats
- Snapshot immuable + provenance
- Résolution de référents
- Sensing / intake
- Découverte de sources
- État de connaissance structuré

**Familles de problèmes observées :** Action & learning loops break, Distributed intelligence fails to converge, Signal & context loss
