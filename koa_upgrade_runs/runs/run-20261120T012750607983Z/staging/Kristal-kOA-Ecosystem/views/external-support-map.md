# External support map

This view distinguishes **membership** from **support**. None of the items below is a member of the kOA Digital Ecosystem merely because it supports a capability.

## Pattern source

- **Decidim** → participation-process patterns for ethiKos (`consult`, `deliberate`).

## Deterministic / semantic support tools

- **Ninai** → optional semantic input adapter at the SemantiK boundary.
- **OpenRefine** → external cleaning/reconciliation support for candidate extraction and referent resolution.
- **OpenTapioca** → external Wikidata entity-linking support for referent resolution.
- **Grammatical Framework (GF)** → external execution/grammar authority supporting multilingual realization.

## Boundary rule

`supports capability` ≠ `part of kOA Digital Ecosystem` ≠ `owns kOA state`.
