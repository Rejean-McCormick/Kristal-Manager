# Support boundary map

## kOA Digital Ecosystem members

Membership is expressed with `koa:part_of → koa:digital-ecosystem` and domain-specific ownership relations.

## Independent supporting ecosystems

`MA-Gustave GF Language Engineering Ecosystem` is represented with `scope = supporting_ecosystem` and `integration_state = independent_support_not_member`. Its children use `koa:part_of_supporting_ecosystem`, **not** `koa:part_of → koa:digital-ecosystem`.

## External support / references

GF, Decidim, Ninai, OpenRefine and OpenTapioca use support/reference relations only. Their presence in a workflow does not transfer authority or membership.

## Invariant

`Support ≠ appartenance`: a support tool can be essential to a workflow while remaining replaceable, optional, external or independently governed.
