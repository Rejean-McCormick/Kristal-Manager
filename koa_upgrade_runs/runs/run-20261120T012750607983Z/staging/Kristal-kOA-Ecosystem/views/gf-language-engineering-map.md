# GF language-engineering support ecosystem

The MA-Gustave systems form an **independent supporting ecosystem** around external authority **Grammatical Framework / RGL**. They support kOA multilingual capabilities without becoming members of the kOA Digital Ecosystem.

```text
GF / RGL
  = execution + structural authority

GF RGL AI Compendium
  = contracts + evidence rules + engineering workflows + gates
          │
          ▼
GF Wordbench
  = native GF execution + diagnostics + regression + preserved evidence
          │
          ├──────────────► GF Observatory
          │                 = read-only maturity/readiness projection
          ▼
Ars Magna Lulli
  = multi-project GitOps orchestration + promotion/evidence indexing
          │
          ▼
validated immutable grammar / PGF + evidence
          │
          ▼
SemantiK conformance / RuntimeSet release boundary
          │
          ▼
kOA multilingual runtime capabilities
```

## Authority boundaries

- GF decides typing, compilation, parsing, linearization, generation, morphology and PGF production.
- Compendium does not compile or declare execution success.
- Wordbench does not become linguistic truth or edit source autonomously.
- Lulli orchestrates but does not reinterpret validation verdicts.
- Observatory reads/aggregates evidence and does not compile or modify workspaces.
- Human reviewers retain linguistic/publication acceptance.
- SemantiK consumes validated artifacts only after its own conformance/release boundary.
