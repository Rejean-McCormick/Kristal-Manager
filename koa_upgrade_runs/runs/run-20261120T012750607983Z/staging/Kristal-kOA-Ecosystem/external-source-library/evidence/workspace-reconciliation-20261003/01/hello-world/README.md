# HELLO WORLD
## Autopsie d’un Clown Royal

**HELLO WORLD** est un album conceptuel en français construit comme une **autopsie chantée de King Klown**.

## Écouter l’album

[**HELLO WORLD — Playlist Suno**](https://suno.com/playlist/0a667dce-660e-4a36-bf35-a704bdf2b187)

---

Mais ce dépôt n’est pas seulement le dossier d’un album terminé ou en cours de production. Il sert aussi de **template de travail pour construire une œuvre conceptuelle complexe avec l’aide d’outils d’IA**, tout en gardant un canon clair, des contraintes explicites, des voix distinctes, des motifs cohérents et une trace exploitable de l’architecture créative.

---

## L’album

L’album suit **Pierre Carrey**, qui tente de déterminer où King Klown commence, de quoi il est fait, ce qui lui appartient réellement — et surtout **où il finit**.

Il ne dispose pas d’un corps à disséquer.

King Klown est traité comme un objet construit à partir de :

- récits ;
- archives ;
- rôles ;
- symboles ;
- systèmes ;
- fonctions ;
- traces ;
- dépendances ;
- provenance.

L’autopsie devient donc une forme de reverse engineering culturel :

> **SURFACE → TRACE → FONCTION → SOURCE → HORS CONTEXTE**

À mesure que Pierre remonte la provenance de King Klown, son enquête dépasse progressivement le personnage lui-même.

La question :

> **Où finit King Klown ?**

devient peu à peu :

> **Jusqu’où peut-on suivre la provenance d’une création ?**

L’album se termine lorsque cette recherche atteint **L’Auteur**.

Les derniers mots sont :

> **Hello World.**

Rien ne vient après.

## Un album, mais aussi un template de travail

Ce repository documente une méthode de création.

L’objectif n’est pas de conserver toutes les hésitations, toutes les versions ou toutes les discussions qui ont mené au résultat. Il conserve plutôt **l’état actuel de l’œuvre et les structures nécessaires pour continuer à la développer sans perdre sa cohérence**.

Cette organisation peut être réutilisée pour d’autres projets narratifs, albums conceptuels, univers fictionnels, jeux, livres ou œuvres hybrides.

Le principe est de séparer plusieurs couches qui sont souvent mélangées pendant la création :

### 1. Le canon

Ce qui est actuellement vrai dans l’univers.

Le canon évite qu’une nouvelle session de travail réinvente involontairement :
- les identités ;
- les relations ;
- les événements ;
- les limites du monde ;
- les règles déjà décidées.

### 2. La thèse artistique

Ce que l’œuvre cherche réellement à explorer.

Elle permet de distinguer :
- le sujet apparent ;
- le sujet profond ;
- les questions centrales ;
- ce que l’œuvre ne doit pas devenir.

### 3. Les fils narratifs

Les arcs qui traversent plusieurs morceaux sans devoir être expliqués à chaque fois.

Par exemple :
- l’autopsie ;
- la provenance ;
- l’identité de King Klown ;
- l’enfant ;
- le `Oui` ;
- la fin de King Klown ;
- L’Auteur.

### 4. L’architecture des voix

Chaque personnage possède une fonction et une grammaire propres.

Dans cet album :

- **Pierre Carrey** observe, doute, interprète et synthétise ;
- **Koali** compare, calcule, corrèle et suit les provenances ;
- **King Klown** apparaît surtout par traces et archives ;
- **Réjean** constitue une couche historique ambiguë ;
- **L’Auteur** apparaît à la frontière finale.

Une règle importante du projet :

> **Une chanson = une conscience dominante.**

### 5. L’architecture des morceaux

Chaque chanson doit avoir :

- une découverte ;
- une image dominante ;
- un noyau lyrique ;
- une fonction dans l’arc global ;
- au moins une chose laissée inexpliquée.

Cela empêche l’album de devenir une dissertation découpée en douze morceaux.

### 6. Les motifs

Certains mots et images reviennent avec une signification transformée :

- la trace ;
- le bord ;
- le fil ;
- la source ;
- le `Oui` ;
- continuer ;
- la main ;
- la pièce.

Le motif ne doit pas simplement revenir.

Il doit **changer de fonction**.

### 7. Les contraintes négatives

Une œuvre complexe devient souvent plus cohérente lorsqu’on documente aussi ce qu’elle **ne doit pas faire**.

Exemples :

- ne pas transformer King Klown en simple identité civile ;
- ne pas refaire un manuel de gouvernance ;
- ne pas expliquer la cosmologie dans les paroles ;
- ne pas faire de L’Auteur un gag de quatrième mur ;
- ne pas transformer Koali en humain ;
- ne pas faire renaître King Klown après sa fin.

Ces contraintes sont aussi importantes que le canon positif.

## Méthode d’écriture

Une règle a guidé la rédaction des chansons :

> **Montrer avant d’expliquer.**

Les concepts peuvent être complexes dans les fichiers d’architecture.

Les paroles, elles, doivent privilégier :
- une image ;
- un geste ;
- une anomalie ;
- une perception ;
- une phrase mémorable.

Exemple :

Plutôt que :

> le modèle temporel est cyclique

l’album préfère :

> **derrière cesse d’être une direction**

Ou :

> **Pas en revenant. En continuant.**

L’architecture peut être intellectuellement dense.

La chanson n’a pas besoin de l’être de la même manière.

## Pourquoi cette structure fonctionne avec l’IA

Un assistant génératif peut produire beaucoup de texte rapidement.

Le problème n’est donc pas seulement la génération.

Le problème est la **continuité**.

Sans structure, un projet long risque :
- les contradictions ;
- les retours en arrière ;
- les motifs surutilisés ;
- les explications répétées ;
- les changements involontaires de ton ;
- la perte du rôle exact de chaque personnage.

Ce repository sert de mémoire de travail structurée.

Il permet de fournir à une IA :
- le canon pertinent ;
- les règles de voix ;
- les contraintes ;
- l’architecture d’un morceau ;
- les motifs à préserver ;

sans avoir à recharger l’intégralité du projet à chaque intervention.

Le fichier `13_RAG_INDEX.md` sert précisément de **routeur de contexte** : il indique quels documents consulter selon la question ou la tâche.

---

## Ce que ce template essaie de préserver

Pas seulement la continuité factuelle.

Il cherche à préserver :

- la logique narrative ;
- la densité conceptuelle ;
- l’évolution du langage ;
- la distribution des voix ;
- les révélations ;
- le rythme de l’information ;
- ce qui doit rester ambigu ;
- ce qui doit rester silencieux.

Autrement dit :

> **le but n’est pas seulement de se souvenir de l’histoire, mais de se souvenir de la manière dont l’œuvre doit penser.**

## Point d’entrée du repository

`README.md` est désormais le **seul README du projet**.  
Il consolide la présentation publique de l’album et l’explication du template de travail.

Les fichiers numérotés `01` à `13` sont des documents spécialisés : canon, thèse, fils narratifs, voix, morceaux, langage, motifs, cosmologie, finale, principes, contraintes et index RAG.

## État du projet

Le repository représente **l’état actuel de HELLO WORLD**.

Il est destiné à évoluer avec l’œuvre.

Lorsqu’un choix devient canonique, l’objectif est de mettre à jour les fichiers correspondants plutôt que d’empiler des versions contradictoires.

Le repository n’est donc pas conçu comme un journal complet des changements.

Il est conçu comme une **source de vérité créative actuelle**.
