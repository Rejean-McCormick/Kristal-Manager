## Strategic function

This repository is not a duplicate business plan. It is the execution layer that answers:

> **Which external actor can create the next transferable proof, operator, deployment, integration, distribution channel, revenue opportunity or institutional access point — and what is the smallest credible first action?**

The canonical business plan remains authoritative for detailed offers, monetization and financial doctrine.

## Information classes

- **[DOCUMENTED]** — directly supported by current source material or public evidence.
- **[WEB-VERIFIED 2026-09-23]** — current external information checked against an official source.
- **[DECISION]** — campaign/positioning decision adopted for this wave.
- **[TO VALIDATE]** — plausible or useful, but requiring external verification.
- **[SUPERSEDED]** — historical information retained for provenance but no longer current.
- **[PRIVATE]** — internal campaign context; not for forwarding.

## Rule

> **Large proposition. Precise proof. Explicit limits. Small first action.**

The campaign must not under-represent kOA in order to look reasonable. It must present the actual scale of the architecture, then attach every strong claim to inspectable evidence and a bounded ask.
