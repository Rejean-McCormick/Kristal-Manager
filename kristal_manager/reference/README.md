# Pinned offline reference material

- `unesco-thesaurus-profile.json` and `unesco-thesaurus-baseline.json`: verbatim from user-provided **Kristal Framework v11 draft.4 archive**, under its `spec/v7/reference-kos/` directory. UNESCO is the source authority for KOS URIs and labels; the Kristal v7 baseline is a locally pinned reference.
- `toc-registry-100-seed.example.json`: verbatim from the same Framework archive, under `examples/v7/`. Its KQ associations are design examples, not current authoritative workspace classification.
- `isced-f2013-broad-fields.json`: 11 broad codes drawn from the user-provided Icon Generator v2.4 ISCED-F policy, with display English labels; not an export of UNESCO's full ISCED database.

The Framework profile states UNESCO Thesaurus `CC-BY-SA 3.0 IGO` and includes provenance/source URLs. Preserve attribution when distributing the package.
