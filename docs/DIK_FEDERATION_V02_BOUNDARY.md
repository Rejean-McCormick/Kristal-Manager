# Kristal Manager — inventory versus semantic authority

**Coordination note, 24 November 2026.** Manager owns instance inventory,
not the Framework-defined identity mapping or the domain owner's active
v11 revision. An index with multiple declared canonical artifacts is not an
active-revision marker. Do not choose by date, directory name, size,
preferred wording or most frequent Wikidata QID.

diK provides derived evidence keyed by `(namespace_id, KQ/KP)` and typed
external Wikidata Q/P. A diK `/0.2` operator decision pins the index,
registry, crosswalk, inspected graph and catalog SHA-256 but remains a
**read-only view selection**, not Manager authorization for synchronization,
activation or editing. Keep separate fields for inventory, source validity,
derived selection, Framework authority and release approval.

No instance state, catalog selection, Git remote or persisted source is
modified by this note. Historical v9/v10 inventory stays readable.
