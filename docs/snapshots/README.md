# Historical snapshot material

These archived source indexes represent the **original alpha.12 snapshot**. They are not
current alpha.13 distribution inventories and must not be used to verify updated files.

- `SNAPSHOT_INDEX_20261013_1042.txt` was formerly `SNAPSHOT_INDEX.txt` at root.
- `PACKAGE_MANIFEST_SHA256_alpha12.json` is the prior package manifest, retained for traceability.

The optional root `Nettoyer_anciens_fichiers.pyw` can delete **only** the previous,
byte-identical root `SNAPSHOT_INDEX.txt` from an existing checkout. It does not
remove customized files, scan subdirectories or touch Kristals.
