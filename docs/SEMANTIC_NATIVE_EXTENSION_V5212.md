Offline private candidate generation. Baseline is the exact V5.21.1 generation and its V5.21 ancestor. Logic's 12 formal schema entities come from an explicit formal-schemata registry; their names have no declared language and are not promoted to dictionary labels. Native originals are kept byte-for-byte. Aging's list typed as string is reported with its exact original pointer, not converted.

The run searches owner-scoped JSON in `knowledge-base/corpus` and `knowledge-base/sources` for exact predicate IDs with explicit native labels in referent/predicate/property arrays. Observations require review; nothing is automatically added to dictionaries. The search is not exhaustive over all historical files or external sources.

For each old/new candidate, the run generates a hash-bound registration plan and tests the actual Kit recoverable registrar for all four roles on an isolated state-index copy. Dictionary layers are copied into that isolated workspace; old index entries remain byte-equivalent as JSON values. The existing canonical artifact bytes are not staged or independently revalidated. The temporary profile passes pinned Framework and Kit qualification. This is a private rehearsal, not a production registration, activation, release qualification or independent editorial approval. All candidate identities stay separate from active federation tables. The previous generations remain unchanged. A new private generation is committed only after checks and SQLite integrity/foreign key verification.
