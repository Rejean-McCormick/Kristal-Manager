# Operational private maintenance V5.21.7

The effective private dictionary preserves canonical cells, adds exact scoped historical lexical consensus only to previously unlabeled identities and exposes explicit identifier fallbacks. A fallback is never a linguistic label. The 77 selected graph scopes retain their original lexical qualification; structurally qualified restricted scopes are readable by the new private reader, not by canonical-only mode. All original graph/index/profile/layer bytes are checked against V52161 pins. No historical assertion is selected automatically.

The recursive scan is limited to the active workspaces and recognized V8/native registry and curated dictionary JSON formats. File SHA-256 and completed scan state are persisted; interrupted runs can resume with the same inputs. Re-reading bytes is required to detect drift. Malformed/oversize files are reported. Arbitrary archives, unknown predicate declarations, semantic inference, cross-namespace guesses and unaccepted Wikidata links are not automatically imported. The earlier maintenance receipt is independently checked against the actual source files.

The compact SQLite index provides exact French and English fields. The optional name table is read only when indexed by entity_id; name_kind is kept raw, not guessed. An optional explicit dump scan reads raw entity JSON and retains source revision, exact language labels and aliases, line digest and offset. Resume seeks the decompressed offset (may require re-decompression). The local source fingerprint is not an authenticated dump signature. Neither current dump aliases nor an empty list establishes aliases of the older historical revision. `und` is not mapped to another language.

Run the installer for the pinned baseline and prior receipt. It validates and adds code only, executes tests, then creates `maintenance/REPAIR_V5217_COMPACT` or `maintenance/REPAIR_V5217_DUMP` with an optional dump path. Same incomplete run resumes; completed generations are immutable. Use a new RunId for a new scan. The permanent runner accepts the same options. The current adapter is bound to the validated V52161/V52162 baseline; an evolving canonical baseline needs a new verified receipt. Do not run concurrently with workspace writers or another maintenance process.

`diK/scripts/read_operational_dictionary_v5217.py --run ... --baseline ... --namespace ... --id ... --language fr` returns a canonical/recovered label or marked identifier fallback. `--assertion` reads the selected graph assertion by exact pointer; `--canonical-only` keeps strict canonical gates. This is a local API/CLI, not an integration into existing application GUI or production endpoints. Canonical promotion remains a separate Kit operation requiring appropriate source and review metadata; no fabricated reviewer, no schema change, no public write.
