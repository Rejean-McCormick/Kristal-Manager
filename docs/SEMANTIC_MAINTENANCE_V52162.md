# Semantic maintenance V5.21.6.2 — private scan / 0.1

Manager orchestrates the reusable read-only scanner, Kristalizer interprets explicit native migration maps and observes the optional local EncyK compact index, KristalDiag checks the receipt and original source bytes/pointers, and diK exposes an explicit private-review dictionary lookup. The Integration Pack and Kit pin the existing Framework; the Kit remains the sole canonical registrar.

The first implementation accepts a baseline directory with `active.sqlite` and `report.json` and scans directly listed JSON in `knowledge-base/corpus` and `.kristal/v8` for supported native registry or V8 lexicon contracts in active workspaces with missing KQ/KP labels. It does not search arbitrary prose, nested archives, the full dump, or arbitrary JSON structures. No display label is derived from an identifier string. Exact migration-map anchors remain observations, not approvals. An explicit `und` stays `und`; a label without a language is not inferred. Conflicting labels are retained and not selected. Profile/state drift is listed; the scan is a private observation against a frozen index and not a qualification of the current live profile.

`maintenance.sqlite` is a separate database. The historical baseline, canonical files, public tree, and source index are untouched. `alias_target`, `ambiguous`, and `editorial_issue` inventory remaining issues. The compact index lookup uses Kristalizer's existing exact-ID API: returned label/description are observations with no revision or verified alias data, never substitutions for historical aliases. `COMPLETE` is written only after the separate diagnostic succeeds. Keep run outputs outside source generations. A new run uses a new directory. No automatic cache reuse/resume or canonical promotion is implemented in 0.1.

See `python -m kristal_manager.maintenance_scan --help` and the diK script `scripts/read_maintenance_label.py --help`. Use `--private-review` for the recovered term; the default reads only the canonical index. No production service is changed.
