# V5.21.7.1 — accelerated private maintenance

This additive operation reuses the pinned V5217 compact dictionary. It does not rebuild or change that dictionary, the canonical workspaces or the public repository. Stop the prior dump process before running. The interrupted database is read-only, and only committed records with a matching target set and dump stat fingerprint are copied. The line hashes are retained, not reverified against the compressed stream. This is not source authentication.

Discover up to 512 files, at depth <= 2, and eight compatible SQLite files in wikidata-fast. Only the known entity schema with indexed wid or id is supported; name observations require an entity_id index. Unsupported fast formats are reported, then the compact index is queried for remaining IDs. `name_kind` is retained without interpreting it. No network, no full data scan, no bz2 decompression. Exact language observations from the partial dump are stored separately from historical lexical evidence. `und` never receives a guessed language or aliases. No canonical repairs or new accepted matches. The accelerated SQLite file is a supplemental evidence index, not a replacement operational reader. A new run is created on each invocation, including after interruption. Earlier output remains untouched. Progress measures target lookups, not dump size.
